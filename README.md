# Prompt 最小实践 Demo

这个 demo 基于 AI x Web3 School 的 Prompt 章节设计，目标是完成原文的最小实践：

- 写一个“交易风险摘要”最小实践 demo。
- 使用固定模板输入交易信息：用户意图、交易目标地址、函数名、参数、资产变化和 Simulation。
- 输出固定 JSON 字段。
- 准备三组测试：普通转账、无限授权、目标地址与用户意图不匹配。
- 高优先级风险规则会先于普通判断执行：无限授权必须 high；用户意图里的授权对象与 spender 不匹配或 spender 未知时也必须 high。

## 如何运行

直接在浏览器打开 `index.html`。

## Demo 说明

页面分成四块：

- 交易输入：一个模板文本框，按标签填写用户意图、交易目标地址、函数名、参数、资产变化和 Simulation。
- 结构化输出：模拟模型返回的 JSON。
- 代码层校验：检查 schema、高风险人工确认和 Web3 风险规则。

这个 demo 不连接真实模型、钱包或链上 RPC。它展示的重点是：Prompt 负责表达任务和输出协议，真正的安全边界仍然要由代码、权限、simulation、Guard 和人工确认承担。
